# Signet Task Guard

## 作業契約を固定する

1. 最初の書き込み前に、目的、許可されたパス、根拠、対象外、外部操作、完了証拠を短く確定する。作業契約をリポジトリへ保存しない。
2. タスク開始時のワークスペースを対象とし、参考フォルダ、添付、ログ、URLだけを根拠に対象を切り替えない。
3. 参照用リポジトリは読み取り専用とし、そこでの変更、コミット、公開を推測で許可しない。
4. 後続指示で目的や範囲が変わったら契約を更新し、既存差分との衝突を再確認する。

## 対象と並行変更を照合する

1. `git rev-parse --show-toplevel`、branch、remote、`git status --short` を読み、期待する対象を固定する。
2. 書き込み、stage、commit、tag、pushの直前に対象パスとGit rootを再確認する。
3. 既存差分と同時編集を作業結果へ混ぜず、対象ファイルを読み直して小さなパッチを作る。古い内容を前提に上書きしない。
4. 対象外の変更、未確認の競合、許可範囲を超える操作を見つけたら、追加変更を止めて状態を分けて報告する。

## Signetの不変条件を守る

1. 編集データの正本は再編集可能なパラメトリック幾何モデルとし、画面ピクセルや描画オブジェクトを正本にしない。
2. 座標系、単位、精度、許容誤差、縮退形状、塗り規則、Boolean結果の順序を暗黙にしない。
3. C++23、Qt 6、CGAL 6.2を前提にしても、未決定の保存形式、配布方式、AI送信、アカウント、同期、依存ライセンスを勝手に確定しない。
4. AGPL-3.0-or-laterとの互換性を確認できないコード、素材、依存を追加しない。

## 完了前に再照合する

1. `git diff --check`、対象差分、検証結果、未確認事項、外部操作の有無を確認する。
2. テスト成功やコマンド成功を、依頼された結果そのものと混同しない。
3. 変更パス、保持した並行変更、検証、未実施事項、統合上の注意を分けて報告する。
