# Security policy

If GitHub Security Advisories' private vulnerability reporting is enabled for
this repository, use the repository's Security tab, Advisories, and
"Report a vulnerability" to submit a private report. Include the affected
version, reproduction steps, and impact, but do not include secrets or
unnecessary personal data.

This repository does not publish a verified security email address. If private
vulnerability reporting is not enabled, do not put vulnerability details in a
public issue. Open a public issue only to request a private contact channel,
without including sensitive details, or use another private channel explicitly
provided by the repository maintainers.

Signet is local-first and currently has no account, sync, or telemetry service. Reports about unsafe file parsing, native command invocation, dependency vulnerabilities, or data exfiltration are in scope.
