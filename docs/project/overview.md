# Signet 製品概要

Signetは、幾何学図形の組合せから、創作設定に登場する家紋、印章、宗教記号、国家章、魔術記号、組織ロゴを制作するデザインアプリである。

自由描画を中心にせず、円、円弧、黄金長方形とその派生図形を配置し、移動、変形、対称配置、結合、交差、切り抜き、分割、領域選択によって再編集可能な形を構成する。

## 確定している要求

- 幾何学的な整合性と直感的な操作を両立する。
- グリッド、スナップ、中心線、整列、等間隔配置、角度補助、黄金比補助、対称操作を提供する。
- 図形の中心、半径、変換、構成関係を確認できる。
- macOS 26のみを対象とする。
- Apple Silicon `arm64`のみを対象とする。
- AGPL-3.0-or-laterを採用する。
- 自然言語と任意の参照画像から、編集可能な幾何学ロゴを生成する限定MVPを提供する。

## 今後仕様化する事項

- レイヤー、色、線、透明度の仕様。
- 保存形式と書き出し形式。
- 初期図形の範囲と拡張方針。
- AI providerの配布・契約条件、正式な保存形式、利用時のデータ送信境界の拡張。
- Boolean操作の配置方式と複数選択。
- snap/alignment UIの既定値とCanvasへの接続。
